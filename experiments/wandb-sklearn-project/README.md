# W&B Scikit-Learn Project

> An example project that wires Weights & Biases into a scikit-learn pipeline: experiment tracking, hyperparameter tuning and model evaluation.

Trained a model last week and can't remember which settings gave the good result? That is the problem experiment tracking solves. Open the modeling notebook to see it logged to W&B.
