# Fonts

Self-hosted so the site loads no third-party font service (smaller page, no request to Google, works offline).
Latin subset only; other scripts fall back to the system font.

| File | Font | Used for |
| --- | --- | --- |
| `inter.woff2` | Inter (variable, weights 400 and 600) | page text, buttons |
| `pt-sans-400.woff2` | PT Sans | Docsify's base font (`--font-family`) |
| `jetbrains-mono-400.woff2` | JetBrains Mono | code |

All three are licensed under the SIL Open Font License 1.1 (Inter: The Inter Project Authors; PT Sans: ParaType; JetBrains Mono: JetBrains s.r.o.), which allows bundling and redistribution.
