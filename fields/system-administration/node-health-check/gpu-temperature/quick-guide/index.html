Add GPU Temperature Rules to a Health Check

Quick guide: a ceiling rule that drains above a limit, then an idle timer that warns before it drains, with a read-only fleet scan first.

Quick guide for The Ceiling Rule and The Idle Timer. Do the ceiling first, then the idle timer. You will end with one rule that drains above a ceiling and never drains on a failed read, and a second that drains only after a warm idle GPU stays warm for a window.

Before you start

  • A health-check script you can edit, and a test node.
  • dcgmi installed and the DCGM host engine running.
  • Your GPU's limits: nvidia-smi -q -d TEMPERATURE.
  • For the idle timer: scontrol on the node, an ssh key loaded for the scan, and your nodes in nodelist.yml (a nodes: list, one - name per line).

Part 1: the ceiling rule

  1. Read all GPUs once.
   dcgmi dmon -e 150,203,252 -c 1

Expect: one row per GPU, for example GPU 0 38 0 12 (temperature, utilization, memory). If not: list the fields your version knows with dcgmi dmon -l.

  1. Choose a ceiling below your GPU's slowdown limit and set it once.
   GPU_TEMP_CEILING=87      # example value: take yours from the nvidia-smi output in Before you start

Expect: one variable the rule reads.

  1. Wrap the call in timeout, skip headers and N/A, and keep the rows.

Expect: GPU_TEMPS holds one index, temp, util, mem line per GPU. If not: if dcgmi failed or GPU_TEMPS is empty, print a warning and return. Do not drain.

  1. Flag and fail the check for any GPU above the ceiling.
   msg="GPU_TEMP_CRITICAL: GPU-$idx at ${temp}C (ceiling ${GPU_TEMP_CEILING}C)"

Expect: a syslog line like nhc: GPU_TEMP_CRITICAL node=gpu-node-12 GPU-3 at 89C (ceiling 87C) and a drain at the end of the run. If not: check that the flag line reaches syslog and your alerts.

Part 2: the idle timer

  1. Set the parameters (example values: choose yours from your fleet).
   GPU_IDLE_TEMP_MAX=45
   GPU_IDLE_WINDOW_MIN=10
   GPU_IDLE_MEM_MAX_MIB=1024
   GPU_TEMP_STATE_DIR="/var/tmp/nhc_gpu_temp"

Expect: four variables at the top of the temperature block.

  1. Gate on the node state.
   scontrol show node $(hostname -s) | grep -E 'State=|GresUsed|AllocTRES'

Expect: apply the idle rule only when State= starts with IDLE and does not contain COMPLETING. If not: on MIXED or ALLOCATED, apply the ceiling only and clear the idle timers.

  1. Treat a GPU as idle only if utilization is 0% and memory in use is at most GPU_IDLE_MEM_MAX_MIB.

Expect: anything else clears that GPU's timer.

  1. On first sight above GPU_IDLE_TEMP_MAX, record the time and warn only.

Expect: /var/tmp/nhc_gpu_temp/gpu<N>.hot_since exists, and no drain yet.

  1. Drain only if the GPU is still idle and hot after the window.

Expect: GPU_TEMP_IDLE_HIGH: GPU-<n> idle above 45C for <m>m and a drain at the end of the run. If not: discard the timer when the node leaves IDLE, utilization rises, memory is in use, the GPU cools, or the recorded time is before the last boot or in the future.

  1. Before enforcing, scan the fleet read-only.
   eval "$(ssh-agent -s)"; ssh-add
   ./gpu_temp_scan.sh nodelist.yml

Expect: a summary with scanned, unreachable and flagged counts, and all_gpus.csv and flagged.csv. If not: unreachable and no-data nodes are unknown, not fine.

If it fails

What you seeLikely causeFix
Every node drains at onceA failed read was treated as hotWarn and skip on a failed read
No temperature rowsdcgmi or the DCGM host engine is downStart the host engine, then re-run Part 1 step 1
Drain never happensCeiling above what your GPUs reachLower it, below the slowdown limit
A node with a live job is flagged idleIdle was defined by utilization aloneGate on node state and memory in use
Idle timer never startsNode not IDLE, or GPU not idleCheck State= and memory in use
Hot GPUs on MIXED nodes are missedThe idle rule skips them by designOnly the ceiling covers them

Roll out and roll back

  • Start with the flag line only and watch syslog for a few days, then let the check drain.
  • Test on a node with the DCGM host engine stopped: it must warn and not drain.
  • For the idle timer: scan first, then run the check with draining off, then enforce.
  • A drained node needs a manual resume, and running jobs are not killed.
  • Roll back the idle timer: restore the previous script and remove /var/tmp/nhc_gpu_temp/.

Don't: drain because a reading failed, and don't define idle by utilization alone.
