# Generative AI - Overview

> Generative AI is software that creates new things: text, code, images, audio, video, simulations. This folder is where to go to see how it is built, served, evaluated and put to work.

You have probably typed a question into ChatGPT. This section is about what sits behind that box: the models, the frameworks that wire them into applications, the tools that tell you whether they work, and the GPUs that make them fast enough to use.
