# Generative AI - Machine Translator

> How a neural network turns a sentence in one language into a sentence in another, from the basic encoder-decoder idea to a notebook with attention.

Translation is awkward for a model: the input and the output are both sequences, and they rarely have the same length or word order. The pages here show the idea that solved it, then a notebook you can run.
