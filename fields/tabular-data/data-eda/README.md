# Data EDA - Overview

> Exploratory Data Analysis (EDA) is looking at your data before you trust it. By the end you'll know where to go to inspect features, draw the right plot and check how columns relate.

A model will happily train on garbage and give you a number anyway. EDA is the ten minutes that tell you whether the garbage is there.
