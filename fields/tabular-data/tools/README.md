# Tabular Data - Tools - Overview

> Three reusable Python files for the chores you repeat on every tabular project: preprocessing, feature engineering and custom pipeline steps. By the end you'll know which file to open before you write the same helper a third time.

You clean the data. Then you build a feature. Then you wrap it for a pipeline. Next project, you do it all again from scratch. These files are the "again", written down once.

| If you are about to... | Open |
|------------------------|------|
| Clean and prepare a raw table | [datapreprocessing](/fields/tabular-data/tools/datapreprocessing.py) |
| Build new columns from existing ones | [featureengineering](/fields/tabular-data/tools/featureengineering.py) |
| Plug your own step into a pipeline | [pipelinetransformers](/fields/tabular-data/tools/pipelinetransformers.py) |
