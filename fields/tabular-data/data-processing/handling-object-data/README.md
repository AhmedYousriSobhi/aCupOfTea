# Tabular Data - Data Processing - Handling Object Data

> Models want numbers, but some columns hold words. By the end you'll know where to look for comparing text values by similarity.

"Cairo", "cairo " and "CAIRO" are one city to you and three different values to a computer. Object columns (text and categories) need care before a model can use them.
