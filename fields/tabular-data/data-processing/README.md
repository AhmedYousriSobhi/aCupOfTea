# Tabular Data - Data Processing - Overview

> The cleaning step, split by the kind of mess you're facing. By the end you'll know which folder handles gaps, repeats, text columns, extreme values or lopsided distributions.

Real data arrives dirty. Cells are empty, rows repeat, a salary has too many zeros. Models don't complain about any of it; they just learn the wrong thing. Find your problem below.

| The mess | Go to |
|----------|-------|
| Some rows are repeated | [handle-duplicated-data](/fields/tabular-data/data-processing/handle-duplicated-data/README.md) |
| Some cells are empty | [handling-missing-data](/fields/tabular-data/data-processing/handling-missing-data/README.md) |
| Columns hold categories or text | [handling-object-data](/fields/tabular-data/data-processing/handling-object-data/README.md) |
| A few values are far from the rest | [handling-outliers](/fields/tabular-data/data-processing/handling-outliers/README.md) |
| Most values bunch up on one side | [handling-skewness](/fields/tabular-data/data-processing/handling-skewness/README.md) |
