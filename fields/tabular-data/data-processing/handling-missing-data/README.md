# Tabular Data - Data Processing - Handling Missing Data - Overview

> What to do about empty cells. By the end you'll know how to find where your data is missing, and two ways to fill the gaps: with the mean, or with a regression.

Empty cells are not all equal. Before you fill anything, find out where the gaps are and whether they follow a pattern. Then pick a fill strategy.

| Step | Page |
|------|------|
| 1. Find the gaps | [determine-missing-values](/fields/tabular-data/data-processing/handling-missing-data/determine-missing-values.md) |
| 2. Fill with the average | [mean-imputing](/fields/tabular-data/data-processing/handling-missing-data/mean-imputing.md) |
| 2. Or predict the missing value | [regression-imputing](/fields/tabular-data/data-processing/handling-missing-data/regression-imputing.md) |

"Imputing" just means filling in a missing value with an estimate.
