# Tabular Data - Data Processing - Handling Skewness

> A script for fixing skewed columns. By the end you'll know what skew is and where the fix lives.

Skew means lopsided. Think of incomes: most people cluster at the low end, and a few very high earners stretch a long tail to the right. A column like that can mislead models that expect a more balanced shape. The script reshapes it.
