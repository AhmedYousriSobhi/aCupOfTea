# Tabular Data - Data Evaluation - Overview

> How to tell whether a model is actually good. By the end you'll know which folder has the metrics for your kind of task.

Your model says 95%. Is that great, or is it just guessing the common answer every time? The metric you pick decides what "good" means, so pick it on purpose.
