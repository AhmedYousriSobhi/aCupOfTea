# Tabular Data - Data Evaluation - Classification - Overview

> How to judge a model that predicts categories, starting with the most tempting and most misleading metric: accuracy. By the end you'll know why a high accuracy can still mean a useless model.

A model that always answers "no" can score a high accuracy when "yes" is rare. Looks great. Catches nothing. That trap is the accuracy paradox, and the page below explains it, with a notebook you can run.
