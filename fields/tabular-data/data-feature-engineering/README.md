# Tabular Data - Data Feature Engineering - Overview

> Feature engineering means reshaping your columns so a model can learn from them more easily. By the end you'll know how PCA squeezes many columns into a few, and where the script for choosing how many lives.

Got fifty columns, many of them saying nearly the same thing? PCA (Principal Component Analysis) combines them into fewer new columns that keep as much of the variation as possible. The hard question is how many to keep. The script answers that.
