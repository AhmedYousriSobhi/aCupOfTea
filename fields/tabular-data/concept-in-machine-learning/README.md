# Concept in Machine Learning - Overview

> Four short concept pages on the ideas underneath tabular machine learning. By the end you'll know the difference between predicting a label, predicting a number and finding groups with no labels at all.

Before any model, one question decides almost everything: do you have an answer column to learn from, and is it a category or a number? These pages sort that out.
