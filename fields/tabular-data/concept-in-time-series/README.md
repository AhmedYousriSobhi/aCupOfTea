# Concept in Time Series - Overview

> A concepts page and a hands-on notebook for data where the order of the rows matters. By the end you'll know what makes a time series different from an ordinary table.

Shuffle the rows of a normal dataset and nothing changes. Shuffle a time series and you've destroyed it, because yesterday matters to today. That one fact shapes everything on these pages.

Read the theory first, then run the notebook.
