What this assumes
The picture is made up in code (128 × 128). Noise comes from a seeded generator, so a run repeats. Filters are weighted votes (correlation); the Gaussian-like kernel is the binomial 1-2-1 (or 1-4-6-4-1) kernel, which sums to 1. The smooth patch is a 26 × 18 area of the ramp, outlined in the pictures, with no edges in it. The window at the border uses the border rule you pick; reflect is OpenCV's default style (the mirror does not repeat the edge row).

Part of Digital Image Processing, Pixel Town. The pictures are drawn in code, and the numbers are checked against an independent script.
