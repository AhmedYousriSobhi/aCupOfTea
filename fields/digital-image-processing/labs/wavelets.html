What this assumes
The row transform is the page's unnormalized form (average and half-difference). The picture transform is the orthonormal Haar transform, which divides by √2 instead so that it preserves energy; the structure is identical, and a threshold means a coefficient size in that form. Each level splits the current approximation into four quarter-size pieces. Thresholds touch detail coefficients only, never the approximation. Noise is Gaussian from a seeded generator, so a run repeats.
