3Two customers, one pull twice

Expected values always add. Variances add only when the pulls are independent (the card goes back in the bag).

What this assumes
Cards are put back after each pull, so every pull has the same table of chances. The variance here divides by the number of cards, because the bag is the whole population. Simulated pulls use a seeded generator, so a run can repeat.
