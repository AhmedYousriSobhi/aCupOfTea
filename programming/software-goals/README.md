# Software Goals - Overview

> What "good software" means beyond "it runs". By the end you'll know which qualities to aim for and where to start.

Code that works today and breaks tomorrow isn't done. Software goals are the qualities you want on top of correctness, and each one gets its own folder here as the section grows.
