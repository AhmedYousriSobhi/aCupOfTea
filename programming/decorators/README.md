# Decorators - Overview

> Python decorators and their applications in data science. By the end you'll know what that `@something` line above a function is doing, and why you'd write one.

You've seen it: a line starting with `@` sitting on top of a function. A decorator wraps a function with extra behavior without you editing the function itself. Write the wrapper once, reuse it everywhere. That's the whole trick, and it's why decorators keep code clean.
