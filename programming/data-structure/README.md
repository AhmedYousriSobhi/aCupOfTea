# Data Structure

> A notebook walkthrough of the way programs organize data, so you can pick the right container instead of defaulting to a list.

Every program is, at heart, data plus the code that moves it around. How you arrange that data decides whether your code feels instant or crawls. This folder is a notebook on exactly that.

The illustrated content are extracted from book: __Data Structures & Algorithms in Python__

The book is free to use.

Book Link: http://xpzhang.me/teach/DS19_Fall/book.pdf
