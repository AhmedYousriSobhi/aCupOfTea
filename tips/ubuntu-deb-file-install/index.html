Install deb file from Command Line

To install deb package from CL, simply run:

sudp dpkg -i <package.deb>

Steps to Fix Dependencies Error

  1. Instruct dpkg to "fix" itself. ` sudo dpkg --configure -a `
  1. This will instruct apt-get to correct dependencies and continue to configure your packages ` sudo apt-get -f install `
  1. Reinstall the package ` sudo dpkg -i <package.deb> `

Note:

  • In case of using apt install: ` sudo apt install <package> --reinstall `
